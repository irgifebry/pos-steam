# Repository rules

- Work directly on `main`; do not create feature, fix, or task branches.
- Commit related changes in a small number of focused commits on `main`.
- Push completed commits to `origin main`.
- Before pushing, check `git status`, run relevant checks, and confirm `main` is up to date with `origin/main`.
- Keep all work in this repository's scope. Never force-push, rewrite shared history, or delete branches unless user explicitly asks.
