## 4. Temuan & Observasi

### 4.1 Tidak ada defect blocker

Semua check P0 API lulus. Satu kegagalan awal pada `P0-PAY-02` berasal dari **ekspektasi test yang salah**, bukan bug aplikasi: field `payment.bank` memang berformat `"Nama Bank - Nomor Rekening"`. Ekspektasi diperbaiki, run ulang lulus.

### 4.2 Perbedaan kontrak error auth

Login dengan password salah mengembalikan bentuk Better Auth:

```json
{ "message": "Invalid email or password", "code": "INVALID_EMAIL_OR_PASSWORD" }
```

Bukan envelope standar `{ "error": { "code": "...", "message": "..." } }` yang tertulis di [`docs/backend/README.md`](../../backend/README.md) §6.1. Perlu diputuskan: auth endpoint dikecualikan dari kontrak, atau dokumentasi/response diseragamkan.

### 4.3 Status order total 0

Order ROYALTY Reguler dengan total 0 berakhir `selesai` dengan `paid=false` setelah diselesaikan. Ini sesuai kontrak saat ini (“order selesai tanpa pembayaran tetap selesai”), tetapi perlu keputusan produk: apakah order gratis seharusnya otomatis `paid` atau tetap `selesai` dan tidak masuk laporan omzet. Dampaknya ke rekonsiliasi dan laporan.

### 4.4 Data uji dan angka dashboard

Dashboard/laporan pada run ini masih mencakup data dari percobaan P0 sebelumnya di database lokal. Assertion P0 hanya memverifikasi order yang dibuat pada run ini, tetapi angka agregat tidak bisa dipakai sebagai baseline. Untuk regresi berikutnya, gunakan database QA terpisah atau reset database sebelum run.

### 4.5 Mobile UI dan sebagian sub-assertion belum dieksekusi

Modul mobile F2-080 s.d. F2-092 masih `Belum`. Yang sudah diverifikasi hanya backend API dan CORS. Pengujian manual Expo Web/Expo Go tetap wajib sebelum sign-off.

Beberapa test case F2 berstatus `Lulus (API 26/11, sebagian)` karena alur utama lulus tetapi sub-assertion seperti timestamp, pajak non-zero, uang pas, isi 6 sheet Excel, nilai agregat dashboard, dan exclusion laporan belum dijalankan. Status lengkap ada di [`f2-kasir-inti.md`](../test-cases/f2-kasir-inti.md); status parsial tidak boleh dihitung sebagai cakupan selesai.
